# 首个审批决定在所有面上生效

[English](guide.md) | 中文

## 变更

一次审批请求可能来自本地提示、gateway 客户端或远端传输。此前，对同一请求最后被观察到的答复可能覆盖更早的答复。现在，首个决定对每个面都为该请求定局，之后同一请求的答复会被丢弃而不是生效。

## 迁移

- 允许提交后改主意的客户端，必须把已受理的审批视为定局；控制权属于最先答复的那个面。
- 在别的面已经裁决之后再提交，会拿到已裁决结果，而不是一个可以重试的错误。
- 轮询决定的自动化不得假设自己的提交改变了结果；应回读已裁决的决定。
